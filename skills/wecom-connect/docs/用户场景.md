# 用户场景

按「谁 → 什么情况下 → 说什么 → 得到什么 → 注意什么」组织。每个场景都能照着跑一遍。

---

> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 使用者的日常用法

- **角色**：使用者
- **触发时机**：需要「企微对接」这件事有结果的时候
- **他会说**：`用 wecom-connect 帮我企微对接`
- **需要准备**：企微应用凭据或连接器；待同步的动作
- **拿到什么**：同步执行报告 + 失败清单
- **容易踩的坑**：企微接口需要企业认证与 IP 白名单，未配置时不要假装已执行

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 wecom-connect 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 企微应用凭据或连接器 | ✅ | 缺失会导致输出不可用 |
| 待同步的动作 | ✅ | 缺失会导致输出不可用 |
| 标签体系 | ⬜ | 有则更好 |
| 触达频次规则 | ⬜ | 有则更好 |

## 场景三 · 边界情况（重要）

这几条写清楚做不到什么，比列一堆能力更有用：

- 不处理个人敏感信息的跨系统流转；凭据交由平台的连接器管理，技能内不落凭据
