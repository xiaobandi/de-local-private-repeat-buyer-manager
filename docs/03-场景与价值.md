# 03 · 场景与价值

## 谁在用

已沉淀微信私域但不会运营的门店（68% 运营能力断层，据 R4 调研）

## 三个典型场景

### 场景 A：入群欢迎与打标
- **触发**：事件（客户扫码入群）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：欢迎语 → 引导填写偏好 → 建议标签
- **收益**：替代人工登记，单客省 3 分钟

### 场景 B：每日朋友圈文案
- **触发**：定时（每日 7:30 推送 3 条候选）
- **之后**：结合当日菜品/天气/热点 → 生成"像人话"的朋友圈
- **收益**：解决"每天发什么"枯竭痛点，月省 10 小时+

### 场景 C：社群话题/活动 SOP
- **触发**：定时（每周一推送本周 SOP）
- **之后**：按行业模板生成本周社群互动话题与活动方案
- **收益**：替代代运营社群服务（2000 元/月档）

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 人工 1 人最多管 200 客户（据 R4 调研），AI 辅助下管 1000+；唤醒 5% 沉睡客户即可覆盖年费 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
